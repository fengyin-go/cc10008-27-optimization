# 对比分析回归脚本

纯前端项目没有测试框架；这个脚本用内存版 `localStorage` 在 node 里跑数据层行为回归。

```bash
cd frontend
npx esbuild scripts/compare-check.ts --bundle --platform=node --format=cjs \
  --outfile=/tmp/compare-check.cjs --log-level=error && node /tmp/compare-check.cjs
```

覆盖的口径：

- 阈值口径 = 相对差异百分比；只调阈值时复用未变化切片，仅重算临界带（阈值 ±20%）或判定翻转的切片，显著性判定不因阈值变化而重算。
- 报告发布后判定冻结：后续阈值/显著性变化只生成候选，旧发布报告不被覆盖、仍可下钻。
- 缺失组不按 0 补齐：一侧有维度另一侧缺数时单列未归类行，重复执行不会并入已有差异。
- 维度顺序/大小写规范化：不产生虚假新增，也不产生新判定版本。
- 显著性水平变化生成新判定版本；报告撤销后再生成仍能核对基准快照。
- 方案停用后旧报告可下钻，新阈值修改只能生成候选且不能发布。
- 同一维度两侧类型不同时阻止对比。
- 故障清理：重复明细、残留旧阈值判定、缺失字段、同方案多份当前发布报告；清理可重复执行（幂等）。
- 下钻维度缺失时展示未归类行、不重算旧结论。
